  ## Installation <br>
  Load the project code from Elisha-s-Professional-README-Gen GitHub repository. Once on your local drive on your terminal, install inquirer with the following command: npm install inquirer. Then run the code with: node index.js. Then fill in the questions and your README file will be created. <br><br>
